# Qwen3.5-9B 견적서 파인튜닝 전후 비교 분석

## 결론

Final A는 동일 100장·동일 13개 필드 기준 정확도를 **65.27%에서 98.51%로 33.24%p 개선**했다. 오답 필드는 374개에서 16개로 줄어 **오류의 95.7%를 제거**했다. JSON 파싱 성공률은 99%에서 100%, 채점 필드 완전일치 문서는 11개에서 84개로 증가했다.

## 해석상 한계

현재 validation은 `plan_id` 100개를 학습에서 제외했지만, 검증에 등장한 원본 양식 28종, template 18종, 필드 source sample 66종, 작성자 5종이 모두 학습 데이터에도 등장한다. 따라서 이 결과는 새로운 양식·새로운 필체로의 일반화가 아니라 동일 합성 생성 체계 안에서의 분포 내 성능을 보여준다.

실서비스 배포 판단 전에는 원본 양식 또는 작성자 단위로 겹치지 않는 외부 테스트셋을 만들고, 다품목 문서는 첫 행뿐 아니라 전체 행의 누락·순서·합계까지 평가해야 한다.

## 최종 판단

- **최종 학습 모델을 현재 배포 후보로 채택한다.** 이 모델은 2 epoch 학습을 모두 마친 1,476번째 학습 단계에서 저장한 모델 상태(`checkpoint-1476`)다. 검증 데이터 손실이 0.00713으로 가장 낮아 최종 모델로 선택했다.
- 동일 분포의 합성 견적서 처리 성능은 목표를 달성했다.
- 추가 epoch보다 독립 실문서 테스트와 필기체 오류 12개 문서 분석을 우선한다.
- latency 개선은 관찰됐지만 FP16/BF16 및 캐시 조건이 달라 모델 효과로 단정하지 않는다.
