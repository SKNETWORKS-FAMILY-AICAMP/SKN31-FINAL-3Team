# 대시보드 목록·견적 검증·MR 반려 개선

## 바뀐 점

- 대시보드 더보기/KPI는 카드 확장 대신 별도 목록 화면을 연다. 맨 위 뒤로가기, 검색, 단계 필터, MR 번호/요청 납기일 정렬, 25건 페이지 이동 제공.
- 최근 처리 알림도 독립 목록 제공. 알림에는 과거 단계가 저장되지 않으므로 단계라고 오표기하지 않고 **업무 화면** 필터 및 최신/오래된순 정렬 제공.
- 제시 납기가 RFQ 최초 발송 기록일보다 이전이면 납기 0점과 빨간 안내. 발송 기록이 없으면 RFQ 생성일을 사용하고 그 근거를 안내에 표시한다. MR에서 복사되는 RFQ `transaction_date`는 사용하지 않는다.
- 여러 품목 중 하나라도 잘못된 납기이면 납기 점수 0. 날짜만 있는 자료이므로 같은 날은 허용한다. 재견적은 해당 견적의 원래 RFQ 날짜와 비교한다.
- 공급사 제출 규격과 비고가 모두 비어 있으면 기존 AI/캐시가 만점이어도 규격 0. RFQ의 기준 자체가 없다면 평가 불가로 제외하고 나머지 가중치를 재정규화한다. 비고에 규격을 제출하는 기존 경로는 유지한다.
- 오류 견적을 예외로 탈락시키지 않고 비교표에 남긴다. `warnings`, `requires_confirmation`을 통해 사용자 확인 대상으로 표시한다. 자동 선정은 확인이 필요한 1순위를 그대로 진행하지 않고 사람에게 넘긴다.
- 협력사 선정 행의 ⋯ 메뉴에 **MR 반려 · 취소** 추가. 마감 전에도 가능하며 이유와 확인 절차가 있다. 처리 중 중복 제출/팝업 바깥 클릭 방지.

## 구현 위치

- 프론트 `DashboardView.tsx/.css`: 별도 목록 상태와 필터. 기존 조회된 데이터 범위에서 동작하며 새로운 전체 DB 조회 API를 만들지 않는다. 알림 삭제/숨김 정책도 변경하지 않는다.
- 프론트 `QuotationScoreBreakdown.tsx`: 납기/규격 경고는 compact에서도 빨간 글씨로 표시.
- 프론트 `VendorSelectionView.tsx`: MR 반려 진입 및 진행 중 보호.
- 백엔드 `quotation_models.py`, `quotation_reviewer.py`: RFQ 날짜 근거 추가. RFQ당 최대 1회의 제한된 Communication 조회. 견적별/품목별 반복 조회 없음.
- `quotation_ranker.py`: 점수 상·하한 검증 및 재견적 라운드별 날짜 확인. 저장된 AI 규격 점수도 최종 합산 직전에 검증.
- `auto_progress.py`: `requires_confirmation`은 감점 목록과 별도로 자동 선정 차단 조건에 반영.
- `services/mr_cancellation.py`: 모든 재견적 차수와 ERP에 직접 연결된 RFQ까지 탐색. 공유 문서/PO 존재 여부를 **첫 변경 전에** 검사한 후 SQ → RFQ 순으로 ERP 표준 취소 또는 초안 폐기.
- `workflow_service.reject_case`: 대기 없는 그래프/케이스 잠금 아래 재조회 후 처리. MR 취소가 성공한 뒤 작업·알림 및 케이스 상태 정리. 동시 처리 시 HTTP 409, 연결 PO/공유 문서는 HTTP 422.

## 데이터 보호와 제한

제출 문서는 강제 삭제하지 않으며 ERPNext 자체 연결 검증을 우회하지 않는다. 초안에는 기존 ERP 폐기 기능을 사용한다. 다른 구매 건과 공유하거나 이미 PO가 있는 경우 이 화면에서 처리하지 않는다.

ERP API 여러 건은 단일 DB 트랜잭션이 아니다. 중간 실패 시 일부 문서가 취소된 상태일 수 있으며 오류를 표시한다. 재시도는 이미 취소된 문서를 건너뛴다. 회사 정책·환경변수·메일 설정은 변경하지 않는다.

이미 저장된 순위 결과를 일괄 변경하지 않는다. 기존 화면의 과거 점수는 **AI 분석/견적 다시 확인**으로 재계산해야 최신 검증이 적용된다. 새 분석·신규 견적 반영 경로에는 자동 적용된다.

## 검증

- 실제 운영 문서 취소/메일 발송 없이 모의 ERP로 검증.
- 과거/당일 납기, 다품목, 소요일 환산, 재견적 원래 날짜, 빈 규격+만점 캐시, 기준 없음, 비고 규격 제출, RFQ 생성일/발송 기록일 선택 회귀 테스트.
- 모든 차수+ERP 직접 연결 RFQ 정리 순서, 공유 RFQ/SQ/연결 PO 보호, 이미 취소된 문서 재시도, 실행 중/완료 건 보호, MR 취소 실패 시 케이스 완료 처리 방지 테스트.
- compact 견적 표의 빨간 경고 및 평가 제외 안내 렌더링 테스트.
- 로컬 모의 대시보드에서 더보기·필터·검색·뒤로가기 시각 검증. 실제 로그인 상태의 운영 MR 취소는 수행하지 않음.
