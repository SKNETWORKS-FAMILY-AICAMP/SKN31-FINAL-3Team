01↻

ITEM 규격 보완 루프

AI가 대체품과 부족 규격을 ERPNext 코멘트로 안내합니다. 요청 내용은 DB에 저장해 재요청 시 다시 검증하며, 최대 5회 후 구매팀 승인으로 전환합니다.

AI + DB + ERP COMMENT
02≈

MR 선제 검토

기존 거래 이력의 이상 수량을 경고하고, 동일 Item Group·핵심어·재고를 통과한 대체품을 규격 유사도 순으로 최대 5개 제안합니다.

RULE + AI
03⇄

업무 배정과 구매 경로

회사 카탈로그 기준으로 담당자를 배정·이관하고, 긴급 요청과 납기일로 정렬합니다. 회사별 정책을 반영해 구매와 입찰을 사람이 확정합니다.

POLICY + HUMAN GATE
04◎

다단계 Supplier 탐색

나라장터 기업 → 최근 30일 거래 → Tavily Web Search 순으로 후보를 찾고, Naver API로 연락처를 보강해 ERPNext Supplier에 저장합니다.

FUNNEL SEARCH
05Ⅱ

견적 대기와 재개

RFQ 발송 후 흐름을 중단하고 회신을 기다립니다. 미회신 시 재확인하며, RFQ 내용 보완 요청이 오면 수정·발송 단계로 되돌아갑니다.

PAUSE · RESUME · RETRY
06≡

비정형 견적과 Top-K

이메일·파일 견적을 Hugging Face LLM으로 추출해 ERPNext에 등록하고, 누락·유효기간·이상 단가를 검토한 뒤 단가·납기로 Top-K를 제안합니다.

DOCUMENT AI + RANKING
bidding flow의 차별점추천 화면에서 끝나지 않고, ERP 기록·외부 회신·예외 재처리까지 다음 업무를 실제로 이어갑니다.
